### Acteurs

Le tableau ci-dessous récapitule les acteurs pouvant être impliqués dans les différents processus collaboratif

| | | |
| :--- | :--- | :--- |
| Acteur | Type d'acteur | Description |
| [BPI ENS](ActorDefinition-BPI-ENS.md) | Person | Entreprise du Numérique en Santé. |
| [BPI Utilisateur](ActorDefinition-BPI-Utilisateur.md) | Person | Il peut s'agit d'un professionnel du secteur santé, médico-social ou social. Il peut également s'agir du patient ou de l'usager lui-même. |
| [BPI Instance Logicielle](ActorDefinition-BPI-Instance-Logicielle.md) | System | Installation en production d'une version d'un logiciel sur un même serveur physique ou logique. |
| [BPI Serveur Multi-Terminologies](ActorDefinition-BPI-Serveur-Multi-Terminologies.md) | System | Portail de publication de ressources sémantiques de l'ANS via IHM, API REST spécifique et API FHIR. |
| [BPI Système d'Information](ActorDefinition-BPI-Systeme-Information.md) | System | Application permettant la gestion de données de santé ou sociales de patients ou usagers. |
